HTML5 + CSS3 + JavaScript

웹페이지를 만들기 위한 기본 언어인 HTML, 디자인을 꾸미는 CSS, 동작을 넣는 JavaScript를 간단하게 이해하고 연습해볼 수 있는 페이지입니다.

HTML5

구조를 만들어요

문서의 제목, 목록, 이미지, 버튼 등 페이지의 내용을 정리하고 의미를 부여합니다.

CSS3

모양을 꾸며요

색상, 간격, 폰트, 배경, 레이아웃 등을 설정해 예쁜 화면을 만듭니다.

JavaScript

동작을 넣어요

클릭, 입력, 애니메이션, 계산 등 사용자와 상호작용하는 기능을 추가합니다.

예제 살펴보기

<button onclick="showMessage()">
  버튼 클릭
</button>

<script>
  function showMessage() {
    alert("안녕하세요!");
  }
</script>
버튼을 눌러보세요!
